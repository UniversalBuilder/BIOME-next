# Contributing

Use generated examples when reporting problems. Do not attach real project
catalogues, research images, emails, credentials or personal exports.

Run the Python and JavaScript tests described in README.md before submitting
changes. Windows CI runs both suites. Build and standalone application checks
must also be performed for changes affecting packaging or desktop integration.

Keep original image data separate from catalogue records. Preserve user-authored
content and supported project formats. Interface translations must not translate
project notes or other user content.
