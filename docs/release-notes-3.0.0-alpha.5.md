# BIOME-next 3.0.0-alpha.5 — readable delivery preparation

Delivery contents are now grouped by notebook entry, with readable titles, dates, captions, versions and original filenames. Preview images, scripts, notes and messages before choosing what to transmit. Search and type filters preserve the selection. Source messages and technical archives are separate and excluded unless explicitly selected.

Change a display label for one delivery without renaming source files. Review the selected documents, recipient message and external-data choices before creating the ZIP. The frozen manifest and readable index preserve those labels and provenance. Changed selections are rejected rather than silently transmitted.

Quit BIOME, extract **BIOME-Windows-portable-3.0.0-alpha.5.zip** into a new program folder, and launch **BIOME/BIOME.exe** with `_internal` beside it. Open the existing catalogue; no project-format migration is needed. Illustrated offline guides are included.

This remains an unsigned Windows x64 alpha, with a French interface and a dedicated Chrome/Edge application window. Automatic AI naming is not included. Unsupported binary formats can be downloaded but do not have a rendered preview. Preview text is bounded; the full selected file is copied into the delivery.

Validation: 63 Python tests, JavaScript sorting, actual upload-form validation and delivery-selection tests, compiled standalone checks, and an actual browser selection/preview/review/ZIP workflow using fictional demo data.
