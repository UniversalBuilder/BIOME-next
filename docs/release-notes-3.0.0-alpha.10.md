# BIOME-next 3.0.0-alpha.10 — Correct project dates

Project information now includes an editable project date and an optional known activity date for historical imports and current projects. Unknown contacts can remain blank in 1.1 projects. A valid date found at the beginning of an original folder name or title is offered for explicit confirmation.

The confirmed date updates the sortable project list, future data-folder suggestions and future delivery summaries. Original import metadata and technical creation timestamps remain preserved. Existing folders and past delivery archives are unchanged. Blank dates explicitly remain unknown.

Information corrections no longer count as recent activity. The known activity date supplements incomplete history; later dated sessions, receipts and framing updates remain authoritative. These metadata fields create no sessions or recorded time in the activity report.

Update: quit BIOME, extract BIOME-Windows-portable-3.0.0-alpha.10.zip into a new program folder, keep _internal beside BIOME.exe, and reopen your existing catalogue. No project-format migration is required. This remains an unsigned Windows x64 alpha with a French interface.

Validation: 91 Python tests, JavaScript regression checks, compiled standalone date editing and a browser workflow confirming a folder-derived date on a fictional historical project with no known contact.
