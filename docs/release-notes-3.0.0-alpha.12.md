# BIOME-next 3.0.0-alpha.12 — Vivid Pandora palette

This release restores the energy of BIOME’s original colour palette while retaining BIOME 3’s clearer navigation, typography and workflows.

The background now combines blue-violet gradients with cyan lighting. Primary actions use blue-indigo, imports violet, exports and conservation actions green, and deliveries pink-violet. Catalogue and report metrics have brighter values and distinct accents.

Project status labels remain visible, with blue for active work, amber for review, green for completed projects, orange for paused work and violet for preparation. Notebook entries gain colour markers by type. Reports use luminous gradients and stable category colours derived from their labels; unrecorded categories remain grey. Values, units, calculations and project formats are unchanged.

Contextual help, mouse/keyboard tooltips and preserved drafts remain available. The illustrated guides include updated screenshots of the accepted palette.

## Update

Quit BIOME, extract **BIOME-Windows-portable-3.0.0-alpha.12.zip** into a new program folder, keep `_internal` beside `BIOME.exe`, and reopen your existing catalogue. No project-format migration is required. This remains an unsigned Windows x64 alpha with a French interface.

## Validation

91 Python tests, the three JavaScript regression checks, browser checks across workspaces and mobile layouts, preserved help/drafts, unchanged report values and distinct status colours, plus compiled standalone checks from a relocated installation. Checks use fictional data. Main button gradient endpoints were checked for normal-text contrast of at least 4.5:1; this is not a complete accessibility audit.
